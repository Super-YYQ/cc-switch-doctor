## 2. `[1M]` marker — real semantics

Claude Code declares **1M context capability** by appending a local suffix:

```text
ONE_M_CONTEXT_MARKER = "[1m]"   // claude_desktop_config.rs
```

- Matching uses **case-insensitive** compare (`eq_ignore_ascii_case` / `.toLowerCase().endsWith("[1m]")`).
- Upstream APIs generally **reject** this local marker as part of the model id.
- CC Switch strips it **before** forwarding the request body to the real provider.

Therefore:

```text
Configured model: GLM-5.2[1M]
Wire / outbound model: GLM-5.2
```

This is **not** “switching to another model”. It is the normal runtime of the current config.

## 3. CC Switch strip rule (exact)

From `model_mapper.rs::strip_one_m_suffix_for_upstream`:

```rust
pub fn strip_one_m_suffix_for_upstream(model: &str) -> &str {
    let trimmed = model.trim_end();
    let marker = ONE_M_CONTEXT_MARKER.as_bytes(); // b"[1m]"
    let bytes = trimmed.as_bytes();
    if bytes.len() >= marker.len()
        && bytes[bytes.len() - marker.len()..].eq_ignore_ascii_case(marker)
    {
        return trimmed[..trimmed.len() - marker.len()].trim_end();
    }
    model
}
```

Frontend mirror (`useModelState.ts`):

```ts
export const CLAUDE_ONE_M_MARKER = "[1M]";
export function stripClaudeOneMMarker(model: string): string {
  const trimmedEnd = model.trimEnd();
  if (!trimmedEnd.toLowerCase().endsWith("[1m]")) return model;
  return trimmedEnd.slice(0, -CLAUDE_ONE_M_MARKER.length).trimEnd();
}
```

### Accepted transformations

| Input           | Output    |
| --------------- | --------- |
| `GLM-5.2[1M]`   | `GLM-5.2` |
| `GLM-5.2[1m]`   | `GLM-5.2` |
| `GLM-5.2[1M]  ` | `GLM-5.2` |
| `GLM-5.2 [1M]`  | `GLM-5.2` |
| `GLM-5.2`       | `GLM-5.2` |

### Must NOT transform

| Input           | Output                               |
| --------------- | ------------------------------------ |
| `GLM-[1M]-TEST` | unchanged (marker not a pure suffix) |
| `GLM-5.2[128K]` | unchanged (not a verified marker)    |
| `MODEL[1M]-X`   | unchanged                            |

Doctor **must not** invent stripping for `[128K]`, `[200K]`, or arbitrary bracket suffixes.

## 4. Model mapping order (CC Switch)

`ModelMapping::from_provider` reads Provider `settings_config.env`:

```text
ANTHROPIC_DEFAULT_HAIKU_MODEL
ANTHROPIC_DEFAULT_SONNET_MODEL
ANTHROPIC_DEFAULT_OPUS_MODEL
ANTHROPIC_DEFAULT_FABLE_MODEL
CLAUDE_CODE_SUBAGENT_MODEL
ANTHROPIC_MODEL
```

`map_model(original)` order:

1. Role match by substring (`fable` → `opus` fallback → `haiku` → `opus` → `sonnet`)
2. Subagent equality after `[1M]` strip (preserve original when equal)
3. Default `ANTHROPIC_MODEL`
4. Else keep original

`apply_model_mapping` rewrites `body.model` only when a mapping changes the value.  
`strip_one_m_suffix_for_upstream_from_body` then removes the local marker on the outbound body.

Doctor does **not** reimplement the full proxy mapper. Doctor only:

- strips `[1M]` for Claude/Claude Desktop current-config wire model;
- preserves **source** of each configured role model as `ConfiguredRoleMapping`;
- treats role-mapping success as `CONFIGURED_MODEL_MAPPING_OK`, not `MODEL_VARIANT_OK`.

## 6. Minimal Doctor implementation (v0.1.9)

| Piece                                     | Location                             | Behavior                                                                        |
| ----------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------------- |
| `strip_claude_one_m_marker`               | `ccs_adapter/model_semantics.rs`     | Same suffix rule as upstream                                                    |
| `ModelCandidate` / `ModelCandidateSource` | same                                 | display + wire + source + equivalent_to_current                                 |
| Planner current attempt                   | `diagnostics/planner.rs`             | Sends `wire_model` first; never probes raw `[1M]` as the current-config request |
| Outcome                                   | `diagnostics/engine.rs` + classifier | `LocalMarkerNormalized` success → `CURRENT_CONFIG_OK`                           |
| Role mapping success                      | same                                 | `CONFIGURED_MODEL_MAPPING_OK`                                                   |
| Discovered / other                        | same                                 | `MODEL_VARIANT_OK` with explicit current → success models                       |
| Doctor guess                              | same                                 | `MODEL_GUESS_OK`, `current_config_ok=false`                                     |

### Not copied from the proxy

- Full request body rewrite pipeline
- Role-based client alias routing tables
- Failover / streaming transforms
- Any write to CC Switch DB or process control
- Remote model registry / large model database
