### 1.2 Facts adopted for Doctor

#### A. Claude client role aliases (route probe models)

From `claude_desktop_config.rs` @ path commit `a35209a6e741`:

```text
DEFAULT_PROXY_ROUTES:
  claude-sonnet-5     → ANTHROPIC_DEFAULT_SONNET_MODEL  (supports_1m)
  claude-opus-4-8     → ANTHROPIC_DEFAULT_OPUS_MODEL    (supports_1m)
  claude-haiku-4-5    → ANTHROPIC_DEFAULT_HAIKU_MODEL   (supports_1m)
  claude-fable-5      → ANTHROPIC_DEFAULT_FABLE_MODEL   (supports_1m)
```

From `universalProviderPresets.ts` @ `cd9e025b5a7a`:

```text
NEWAPI_DEFAULT_MODELS.claude:
  model / sonnetModel = claude-sonnet-5
  haikuModel          = claude-haiku-4-5-20251001   // dated pin in NewAPI only
  opusModel           = claude-opus-4-8
```

**Doctor action:** replace hard-coded route model `claude-sonnet-4-20250514` with
profile-bound role aliases (`claude-sonnet-5` default for Claude route probes).
Keep NewAPI dated haiku as optional profile field only — **not** the CCS proxy
route_id for Claude Desktop / Claude Code client protocol.

#### B. Placeholder credential

Confirmed across takeover / proxy services: literal `PROXY_MANAGED`.
Doctor already uses `CCS_PROXY_PLACEHOLDER_TOKEN = "PROXY_MANAGED"` — **keep**.
Never send provider real keys on route probes.

#### C. `/status` / `/health` shape

From `proxy/types.rs` (`ProxyStatus` / `ActiveTarget`):

```text
running: bool
failover_count: u64
current_provider / current_provider_id
active_targets[]: { app_type, provider_name, provider_id }
```

Doctor already parses these fields. v0.1.7 adds **before/after** `GET /status`
around route business requests (already implemented in engine).

#### D. `stream_check.rs` is reachability only

`stream_check.rs` @ `f2c6d48e1970` is **base_url reachability** (any HTTP response
counts as reachable). It does **not** define generate/stream success semantics.
**Do not** reuse it as a protocol parser ground truth.

#### E. Protocol conversion (adopt shapes, not whole proxy)

From transform / streaming path commits:

- Anthropic Messages ↔ OpenAI Chat Completions conversion exists in proxy.
- SSE event names and completion conditions live in streaming modules.
- Doctor should extract **response shape recognition**, text/tool/reasoning
  evidence, SSE event IDs, and error envelopes only — **not** copy the full
  proxy transformer.

### 1.3 Facts explicitly not adopted

| Upstream behavior | Why Doctor rejects |
| --- | --- |
| Live config rewrite / takeover | Doctor is read-only; never touches CCS live config |
| Writing `PROXY_MANAGED` into client auth files | Doctor only **sends** the placeholder on localhost |
| Starting / stopping proxy | Forbidden |
| `stream_check` as generate success | Reachability ≠ protocol OK |
| Copying entire `transform.rs` / `streaming.rs` | License OK (MIT) but scope explosion; minimal adapters only |
| Brand logos / restricted assets | Forbidden by product policy |

### 1.4 Attribution

CC Switch is MIT. When Doctor reuses non-trivial snippets, keep MIT notice and
cite `farion1231/cc-switch` + commit. Prefer re-implementation from observed
shapes over wholesale file copies.

## 2. OpenAI Codex — openai/codex

| Field | Value |
| --- | --- |
| Repository | https://github.com/openai/codex |
| License | **Apache-2.0** |
| Main HEAD (2026-07-21) | `7bb13ab846a3` — page through inherited thread history |
| Focus dirs | `codex-rs/codex-api`, `codex-rs/codex-client`, `codex-rs/app-server` |

### Facts for Doctor

- Responses API is the client protocol for Codex route probes (`/v1/responses`).
- Stream completion is tied to `response.completed` (and related ResponseEvent
  variants); `output: null` can appear on incomplete/error paths.
- First-byte / idle timeouts are client-side concepts; Doctor keeps its own
  bounded timeouts and must not claim “Codex-compatible” from JSON field names alone.

### Not adopted

- Spawning Codex CLI or writing `~/.codex` auth.
- Full app-server agent loop.

Doctor mapping: `OpenAiResponsesAdapter` (future adapter registry) + fixtures
under `tests/fixtures/protocols/openai-responses/`.
